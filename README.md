
# Arbitrary Precision Calculator

## Overview
This project implements an Arbitrary Precision Calculator in C using Doubly Linked Lists.

Unlike normal integer data types, this calculator can perform arithmetic operations on very large numbers that exceed the storage capacity of built-in data types.

## Features
- Addition of large numbers
- Subtraction of large numbers
- Multiplication of large numbers
- Division of large numbers
- Supports positive and negative integers
- Removes leading zeros
- Dynamic memory allocation using Doubly Linked Lists

## Technologies Used
- C Programming
- Doubly Linked List
- Dynamic Memory Allocation


## Sample Input

123456789123456789 + 987654321987654321

## Sample Output

1111111111111111110
